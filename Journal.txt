07/03/2026 to 10/03/2026
Built the auth blueprint which uses two routes, registrion and login. Registration creates an account
by taking the user's details, hashes the password and saves everything to the users table. I 
made sure passwords arent stored as plain text for safety purpose.

Login checks the email in the database, i use check_password_hash to verify the password. I learned hashing 
is one way and cant be reversed so instead of unhashing the stored password i just hash the input again and 
compare the two results.

After login succeceds the server generates a JWT token. This token contains the user's ID signed with a 
secret key.

Without a valid token flask returns 401 unauthorized automatically. Tested eveything using postman

14/04/2026 to 23/04/2026

Built the payment page using. I chose a dark blue, white and black color pattern which was inspired by Paysuite 
(a payment platform from moz). Used google fonts to load two custom fonts, Syne for headings and DM sans for the 
body text. 

The background has two effects created using ::before and ::after pseudo elements a subtle blue grid pattern 
made with two layered linear gradients, and a blue glow blob at the top using a radial gradient.
The navbar uses flex display with justify-content: space-between to push the logo left and the nav links right. 
The Merchant Login button has a blue background and smooth hover transition.

The form has two inputs, phone number and amount each with an icon positioned absolutely inside a 
relative wrapper. Inputs change border color on focus using input:focus. A hidden field carries the merchant ID silently.
The JavaScript intercepts the form submission using addEventListener, prevents the default browser behaviour with 
e.preventDefault(), and sends the data to Flask using fetch() without refreshing the page
